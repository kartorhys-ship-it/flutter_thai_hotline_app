# การพัฒนา

- `SplashScreenUI` เปิด `HomeUI` หลัง 3 วินาที `HomeUI` เก็บสถานะหมวดและเปิด `AboutUI` ผ่าน Navigator
- `TravelUI`, `EmgUI`, `BankUI` และ `PubUI` ส่งข้อมูลให้ `HotlineList` ใช้แสดงรายการและปุ่มโทร
- `Hotline` สร้าง URI แบบ `tel:` โดยคงหมายเลขที่มีศูนย์นำหน้าและตัดขีดคั่น
- แทนช่องภาพใน wireframe ด้วยภาพจากโจทย์ ใช้รูปสัญลักษณ์ผู้จัดทำและข้อมูลรายวิชาในหน้าผู้จัดทำสำหรับรีโปสาธารณะ
- ใช้หมายเลขปลายทางของผู้ให้บริการปัจจุบันสำหรับลูกค้าซิตี้เดิมและทีโอทีเดิม ส่วนรายการอื่นยึดข้อมูลประกอบโจทย์และแหล่งอ้างอิงที่ระบุ
