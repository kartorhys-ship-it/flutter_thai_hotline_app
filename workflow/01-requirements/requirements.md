# เกณฑ์ตรวจรับ

| รหัส | การตรวจ | เกณฑ์ผ่าน |
| --- | --- | --- |
| A07-01 | เปิดแอปที่ 440 × 956 logical pixels | แสดง SplashScreenUI และเข้าหน้าหมวดการเดินทางอัตโนมัติ |
| A07-02 | แตะเมนูด้านล่างทีละหมวด | ชื่อหมวด ภาพ และรายการตรงกับหมวดที่เลือก |
| A07-03 | แตะปุ่มโทรของบริการ | ส่งหมายเลขไปยังตัวจัดการลิงก์ tel ของอุปกรณ์ ถ้าเปิดไม่ได้ให้แจ้งเป็นภาษาไทย |
| A07-04 | เปิดหน้าผู้จัดทำและย้อนกลับ | กลับมาที่หมวดเดิม |
| A07-05 | เลื่อนหน้าจอขนาด 320 × 600 | เข้าถึงรายการสุดท้ายโดยไม่มี layout error |
| A07-06 | เปรียบเทียบกับ mockup | แถบชื่อแอป หัวข้อ ภาพ รายการ ปุ่มโทร และเมนูด้านล่างเรียงตามแบบ |
